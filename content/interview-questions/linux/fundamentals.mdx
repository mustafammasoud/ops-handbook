المراحل الست لإقلاع لينكس:

1. **BIOS / UEFI:**
   - يفحص سلامة مكونات العتاد (POST - Power-On Self Test).
   - يقرأ إعدادات ترتيب الإقلاع (Boot Order) من شريحة NVRAM ويحمل كود MBR أو ملف EFI من قسم ESP.
2. **GRUB2 (Grand Unified Bootloader):**
   - يعرض قائمة أنوية لينكس المتاحة وخيارات التمهيد.
   - يحمل صورة النواة المضغوطة `vmlinuz` وصورة الذاكرة المؤقتة `initramfs` في الذاكرة العشوائية (RAM).
3. **Kernel Initialization:**
   - تفك النواة ضغط نفسها وتتحكم في المعالج والذاكرة.
   - تهيئ مساحات النواة ومحركات الأجهزة الأساسية.
4. **initramfs:**
   - نظام ملفات مصغر مؤقت في الذاكرة يحتوي على وحدات النواة الضرورية للوصول إلى وحدة التخزين الرئيسية (مثل تعريفات NVMe أو iSCSI أو تشفير LUKS). بمجرد تثبيت القسم الجذري الحقيقي `/`، يُلغى تثبيت initramfs.
5. **Systemd (PID 1):**
   - أول عملية تبدأ في مساحة المستخدمين (User Space) برقم المعرف `PID 1`.
   - تحلل شجرة الاعتماديات لملفات التكوين `.service` و `.mount`.
6. **Default Target:**
   - الوصول إلى الهدف الافتراضي (يقابل Runlevels القديمة)، مثل `multi-user.target` للخوادم أو `graphical.target` لمحطات العمل الرسومية.

واصفات الملفات (File Descriptors) القياسية:

| واصف الملف (FD) | الاسم | المصدر / الوجهة الافتراضية |
|---|---|---|
| `0` | `stdin` | لوحة المفاتيح (Keyboard) |
| `1` | `stdout` | شاشة الطرفية (Terminal Screen) |
| `2` | `stderr` | شاشة الطرفية (Terminal Screen) |

أمثلة متكررة في مقابلات DevOps:
```bash
# 1. إرسال المخرجات الطبيعية لملف والأخطاء لملف آخر
command > output.log 2> error.log

# 2. دمج stdout و stderr في ملف واحد
command > all.log 2>&1
# أو بصيغة Bash المختصرة:
command &> all.log

# 3. إخفاء كافة المخرجات والأخطاء في سكربتات Cron
command > /dev/null 2>&1
```
