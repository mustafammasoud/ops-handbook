The six stages of Linux booting:

1. **BIOS / UEFI:**
   - Checks the integrity of gear components (POST - Power-On Self Test).
   - Reads Boot Order settings from NVRAM chip and loads MBR code or EFI file from ESP partition.
2. **GRUB2 (Grand Unified Bootloader):**
   - Displays a list of available Linux kernels and boot options.
   - It holds the compressed kernel image `vmlinuz` and the cache image `initramfs` in RAM.
3. **Kernel Initialization:**
   - The kernel decompresses itself and takes control of the processor and memory.
   - Configure kernel spaces and basic device drivers.
4. **initramfs:**
   - A temporary mini-file system in memory that contains the kernel modules necessary to access the main volume (such as NVMe, iSCSI, or LUKS encryption drivers). Once the real root partition `/` is mounted, initramfs is unmounted.
5. **Systemd (PID 1):**
   - The first process starts in User Space with ID number `PID 1`.
   - Dependency tree analysis for `.service` and `.mount` configuration files.
6. **Default Target:**
   - Access the default target (corresponding to legacy Runlevels), such as `multi-user.target` for servers or `graphical.target` for graphics workstations.

Standard file descriptors:

| File Descriptor (FD) | Name | Default source/destination |
|---|---|---|
| `0` | `stdin` | Keyboard |
| `1` | `stdout` | Terminal Screen |
| `2` | `stderr` | Terminal Screen |

Frequent examples in DevOps interviews:
```bash
#1. Send normal output to one file and errors to another
command > output.log 2 > error.log

#2. Merge stdout and stderr into one file
command > all.log 2>&1
# Or in shortened Bash form:
command &> all. log

#3. Hide all output and errors in Cron scripts
command > /dev/null 2>&1
```
