## 1. Overview

<Callout type="warning" title="أوامر خطرة على GitHub">
- `git push --force` → يعيد كتابة تاريخ الـ remote ويخفي commits؛ البديل الآمن: `git push --force-with-lease` فقط بعد مراجعة `git fetch`.
- `gh repo delete` / `gh repo archive` → عمليات لا يمكن التراجع عنها بسهولة؛ تأكد من اسم المستودع وأخذ نسخة احتياطية قبل التنفيذ.
</Callout>

## 2. Most Used


| Command | What it does | Quick example |
|---|---|---|
| `git status` | يراجع حالة الملفات قبل أي عملية | `git status` |
| `git add .` | يجهز التغييرات للالتزام | `git add .` |
| `git commit -m "msg"` | يسجل تغييرًا برسالة واضحة | `git commit -m "feat: add health check"` |
| `git push -u origin feature/x` | يرفع الفرع ويضبط التتبع | `git push -u origin feature/login` |
| `git pull --ff-only` | يحدث الفرع المحلي بأمان | `git pull --ff-only` |
| `gh auth status` | يتحقق من حالة المصادقة مع GitHub CLI | `gh auth status` |
| `gh pr list` | يعرض Pull Requests | `gh pr list` |
| `gh issue create` | ينشئ Issue جديدًا من الـ Terminal | `gh issue create --title "Bug" --body "..."` |

## 6. Forks and Open Source
<a href="/docs/version-control/git-and-github/forks-and-open-source-contributions" class="inline-flex items-center gap-2 rounded-full border border-border bg-surface px-3 py-2 sm:px-4 sm:py-2 text-xs sm:text-sm font-medium shadow-sm hover:border-accent/50 transition-colors">Full explanation Forks And Open Source Contributions <span aria-hidden="true" style="font-size:1.4rem;">→</span></a>


| Command | What it does | Quick example |
|---|---|---|
| `git clone <fork-url>` | ينسخ الـ Fork الخاص بك محليًا | `git clone git@github.com:YOUR_USERNAME/PROJECT.git` |
| `git remote add upstream <url>` | يربط بالمشروع الأصلي كـ upstream | `git remote add upstream https://github.com/ORIGINAL/PROJECT.git` |
| `git fetch upstream` | يجلب آخر تحديثات المشروع الأصلي | `git fetch upstream` |
| `git merge --ff-only upstream/main` | يحدث `main` من upstream بسرعة | `git merge --ff-only upstream/main` |
| `git push origin main` | يرفع `main` المحدّثة إلى الـ Fork | `git push origin main` |
| `git push origin my-feature` | يرفع فرع الميزة إلى الـ Fork | `git push origin my-feature` |
