## 1. Setup and Configuration

<Callout type="tip" title="Setup tip">
Set your global settings (`--global`) once on your device, and you can override them within a specific repository without `--global`.
</Callout>

<CheatSheet
rows={[
    {
      command: 'git --version',
      does: 'Checks Git installation and current version number',
      when: 'After installation or to ensure certain features are supported',
      example: 'git --version',
    },
    {
      command: 'git config --global user.name "Your Name"',
      does: 'displays or sets the author name associated with all commits',
      when: 'When setting up the development environment for the first time',
      example: 'git config --global user.name "Mustafa Masoud"',
    },
    {
      command: 'git config --global user.email "you@example.com"',
      does: 'Displays or sets the author email address',
      when: 'to link your contributions to your GitHub account',
      example: 'git config --global user.email "dev@example.com"',
},
    {
      command: 'git config --list --show-origin',
      does: 'Displays all applied settings along with the path to each setting file',
      when: 'to track settings conflicts between System, Global and Local',
      example: 'git config --list --show-origin',
    },
  ]}
/>

## 2. Creating and Cloning Repositories

<CheatSheet
  rows={[
    {
      command: 'git init',
does: 'Starts a new local Repository and prepares the .git folder',
      when: 'When starting a new project from scratch locally',
      example: 'mkdir my-app && cd my-app && git init',
    },
    {
      command: 'git clone <url>',
      does: 'Copy a locally existing Repository with the full history of changes',
      when: 'to download a project from GitHub or remote server',
      example: 'git clone https://github.com/user/repo.git',
    },
    {
      command: 'git clone --depth 1 <url>',
      does: 'Shallow clone to the last commit just to save time and space',
      when: 'In CI/CD pipelines or for quick loading of large projects',
      example: 'git clone --depth 1 git@github.com:user/repo.git',
    },
  ]}
/>
