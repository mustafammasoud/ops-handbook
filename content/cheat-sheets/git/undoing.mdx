## 1. Undoing Changes

<Callout type="warning" title="Dangerous commands that require caution">
- `git reset --hard` permanently erases local changes; Safe alternative: `git revert` or `git reset --mixed` to keep your files.
- `git commit --amend` rewrites the last commit; Do not use it if the commit has already been pushed to a remote shared.
</Callout>
<CheatSheet
  rows={[
    {
      command: 'git restore <file>',
      does: 'Cancels unstaged modifications in the file and returns it to the last commit',
      when: 'to undo an unsuccessful attempt on a specific file',
      example: 'git restore src/app.js',
    },
    {
      command: 'git restore --staged <file>',
      does: 'Removes the file from the Staging Area while keeping modifications to the file locally',
      when: 'When you added a file with git add by mistake and want to unprepare it',
      example: 'git restore --staged src/secret.env',
    },
    {
      command: 'git reset --soft HEAD~1',
      does: 'Goes one commit back while keeping the changes stored in Staging',
      when: 'To edit a message or add a file to commit that was just saved locally',
example: 'git reset --soft HEAD~1',
    },
    {
      command: 'git reset --mixed HEAD~1',
      does: 'One commit goes back and returns files to the unequipped Working Tree (default)',
      when: 'to dismantle commit and reconfigure it another way',
      example: 'git reset --mixed HEAD~1',
    },
    {
      command: 'git reset --hard HEAD~1',
      does: 'Moves the branch back and clears all changes from Index and Working Tree (dangerous)',
      when: 'to completely delete the last commit and its changes forever',
      example: 'git reset --hard HEAD~1',
    },
    {
      command: 'git revert <commit>',
      does: 'Creates a new commit that safely reverses and undoes the effect of a previous commit',
      when: 'to undo an existing change on a shared public branch without rewriting history',
example: 'git revert a1b2c3d',
    },
    {
      command: 'git commit --amend -m "new msg"',
      does: 'Replaces the last local commit with a new message or merges newly prepared files',
      when: 'To correct a typo in the last commit message or add a file you forgot',
      example: 'git commit --amend -m "docs: clarify recovery steps"',
    },
    {
      command: 'git reflog -10',
      does: 'Displays the history of the HEAD cursor movement for recovering deleted commits or branches',
      when: 'A safety net for recovering a lost code after a wrong reset or failed rebase',
      example: 'git reflog -10',
    },
  ]}
