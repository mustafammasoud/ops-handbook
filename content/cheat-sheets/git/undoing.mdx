## 1. Undoing Changes

<Callout type="warning" title="أوامر خطرة تستوجب الحذر">
- `git reset --hard` يمسح التغييرات المحلية نهائيًا؛ البديل الآمن: `git revert` أو `git reset --mixed` للحفاظ على ملفاتك.
- `git commit --amend` يعيد كتابة الـ commit الأخير؛ لا تستخدمه إذا كان الـ commit قد رُفع بالفعل إلى remote مشترك.
</Callout>
