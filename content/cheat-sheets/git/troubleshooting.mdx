## 1. Advanced Troubleshooting and Cleanup

<Callout type="warning" title="Dangerous Cleanup Commands">
`git clean -fd` deletes untracked files and folders forever; Always check with `git clean -nd` (dry-run) first and never use it without checking beforehand.
</Callout>
<CheatSheet
  rows={[
    {
      command: 'git reflog -10',
      does: 'Displays the last 10 HEAD moves to restore commits or branches that were deleted or bypassed with reset',
      when: 'Emergency moment when code is lost due to --hard reset or wrong rebase',
      example: 'git reflog -10',
    },
    {
      command: 'git branch recovery/lost-work <hash>',
      does: 'Creates a new branch starting from any commit hash you found in the reflog',
      when: 'to save and retrieve a lost work before it is deleted by the Garbage Collector',
      example: 'git branch recovery/lost-work c7a1b2d',
    },
    {
command: 'git clean -nd',
      does: 'Dry run display of untracked files and folders that will be deleted without actually deleting',
      when: 'A mandatory first step before any warehouse cleaning operation',
      example: 'git clean -nd',
    },
    {
      command: 'git clean -fd',
      does: 'Forcibly delete untracked files and empty folders from Working Tree (dangerous)',
      when: 'to completely clean up construction waste and temporary experiments',
      example: 'git clean -fd',
    },
    {
      command: 'git clean -fdx',
      does: 'Deletes all untracked files including ignored files in .gitignore',
      when: 'to return the repository to a completely clean state as if it were a fresh clone',
      example: 'git clean -fdx',
},
    {
      command: 'git bisect start',
      does: 'Starts a binary search session to detect the exact commit that entered an error or regression',
      when: 'When you discover a bug in your code and want to know exactly when and by whom it caused it',

    },
    {
      command: 'git bisect reset',

      when: 'After finding the commit causing the problem',
      example: 'git bisect reset',
    },
  ]}
