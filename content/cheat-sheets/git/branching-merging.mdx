## 1. Branching and Merging Commands

<Callout type="tip" title="Tip for naming branches">
Use branch prefixes such as `feature/` for features, `fix/` for fixes, and `refactor/` to make them easier to identify.
</Callout>

  rows={[
    {

      id: 'git-branch-all',

    {

      example: 'git switch main',

      command: 'git switch -c <name>',

    {
      command: 'git merge <branch>',
