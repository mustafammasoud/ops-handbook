## 1. Issues & Commit Linking

<Callout type="tip" title="الإغلاق التلقائي للمهام">
استخدام كلمات مثل `Fixes #12` أو `Closes #12` في رسالة الالتزام أو وصف طلب السحب يقوم بإغلاق الـ Issue تلقائيًا بمجرد دمج الفرع في الفرع الافتراضي.
</Callout>

<CheatSheet
  rows={[

      example: 'gh issue list --state open',
    },

      command: 'gh issue list --assignee "@me"',

      when: 'للتركيز على المهام المسؤولة منك في المشروع',
      example: 'gh issue list --assignee "@me"',
