## 1. Issues & Commit Linking
<Callout type="tip" title="Automatically close tasks">
Using words like `Fixes #12` or `Closes #12` in the commit message or pull request description automatically closes the issue once the branch is merged into the default branch.
</Callout>

<CheatSheet
  rows={[
    {
      command: 'gh issue list --state open',
      does: 'Displays a list of all open issues and tasks in the current repository',
      when: 'to know the tasks to be worked on or review existing problems',
      example: 'gh issue list --state open',
    },
    {
command: 'gh issue list --assignee "@me"',
      does: 'Filters and displays only tasks and issues assigned to your account personally',
      when: 'to focus on your responsible tasks in the project',
      example: 'gh issue list --assignee "@me"',
    },
    {
      command: 'gh issue create',
      does: 'Creates a new Issue from the terminal with title, description and labels specified',
      when: 'To quickly report an error or open a new feature request without leaving the terminal',
      example: 'gh issue create --title "Bug: Ingress timeout on 504" --body "Steps to reproduce..."',
    },
    {
      command: 'gh issue view <number>',
does: 'Displays details of the selected problem and associated comments in the terminal',
      when: 'To read the issue context and the team comments as they work on it',
      example: 'gh issue view 42',
    },
    {
      command: 'git commit -m "Fix ... (#42)"',
      does: 'Associates the commit with an issue number to indicate it in the GitHub interface',
      when: 'When writing a commit that resolves or relates to a specific issue',
      example: 'git commit -m "Fix container startup crash (Fixes #42)"',
    },
  ]}
/>
