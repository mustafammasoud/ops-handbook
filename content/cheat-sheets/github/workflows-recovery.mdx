## 1. Advanced Workflows & Recovery

<Callout type="warning" title="Safe Forced Payment">
Never use blind `git push --force` on shared branches. Always use `git push --force-with-lease` to make sure you don't override commits that your colleague has pushed at the same time.
</Callout>
