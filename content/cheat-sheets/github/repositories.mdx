## 1. Repositories Management & Remote Tracking

<Callout type="warning" title="Sensitive files">
Use `git rm --cached` to remove sensitive environment and configuration files (such as `.env`) from the trace log without deleting them from your local machine.
</Callout>

<CheatSheet
  rows={[
    {
      command: 'git remote -v',
      does: 'Displays the names and addresses of registered remote repositories (fetch and push)',
      when: 'to check the remote link before uploading or fetching',
      example: 'git remote -v',
    },
    {
      command: 'git branch -M main',
      does: 'Renames the current branch to main as the default GitHub-compatible branch name',
      when: 'When initializing a new repository and converting master to main',
      example: 'git branch -M main',
},
    {
      command: 'git push -u origin main',
      does: 'Uploads the local branch to the remote repository and sets upstream tracking',
      when: 'On the first master branch push to GitHub',
      example: 'git push -u origin main',
    },
    {
      command: 'git rm --cached <file>',
      does: 'Removes the file from the Staging index but keeps it on the local storage disk',
      when: 'When you accidentally add a sensitive file and want to include it in .gitignore without deleting it',
      example: 'git rm --cached .env',
    },
    {
      command: 'gh repo view',

  ]}
