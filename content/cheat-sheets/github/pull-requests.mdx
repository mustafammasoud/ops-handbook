## 1. Pull Request Workflow & Review

<Callout type="tip" title="Update the branch before opening the PR">
Always fetch and merge or rebuild updates to `main` (`git pull --ff-only` or `git merge origin/main`) before submitting a pull request to avoid merge conflicts.
</Callout>
