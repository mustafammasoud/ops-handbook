## 1. Pull Request Workflow & Review

<Callout type="tip" title="تحديث الفرع قبل فتح الـ PR">
احرص دائمًا على جلب تحديثات `main` ودمجها أو إعادة البناء عليها (`git pull --ff-only` أو `git merge origin/main`) قبل تقديم طلب السحب لتجنب تعارضات الدمج.
</Callout>
