## 1. Authentication and SSH Configuration

<Callout type="tip" title="Prefer SSH keys">
It is always recommended to use SSH keys (type Ed25519) to avoid requesting duplicate passwords and tokens when pushing and fetching.
</Callout>

<CheatSheet
  rows={[
    {
      command: 'ssh -T git@github.com',
      does: 'Tests the connection from your local SSH key to GitHub and confirms that your account is recognized',
      when: 'After generating or adding a new SSH key in GitHub settings',

    {
      command: 'git remote set-url origin <url>',

},
    {

      does: 'Links the local repository to a new remote repository on GitHub',
      when: 'When a new local repository is uploaded for the first time',

    },
    {

      when: 'When setting up the GitHub CLI for the first time on your machine',

    {
      command: 'gh auth status',
