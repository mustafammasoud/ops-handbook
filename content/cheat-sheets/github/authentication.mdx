## 1. Authentication and SSH Configuration

<Callout type="tip" title="تفضيل مفاتيح SSH">
يوصى دائمًا باستخدام مفاتيح SSH (نوع Ed25519) لتفادي طلب كلمات المرور والتوكنات المتكررة عند الدفع والجلب.
</Callout>
