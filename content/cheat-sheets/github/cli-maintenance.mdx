## 1. CLI Tools & Maintenance

<Callout type="warning" title="حذف المستودعات">
أمر `gh repo delete` نهائي ولا يمكن التراجع عنه. استخدم `gh repo archive` إن كنت تريد فقط جعل المستودع للقراءة فقط مع الحفاظ على تاريخه.
</Callout>
