## 1. Overview

<Callout type="warning" title="أوامر خطرة">
- `git reset --hard` → يمسح التغييرات المحلية ويعيد الـ branch؛ البديل الآمن: `git revert` للتاريخ المشترك أو `git reset --mixed` للحفاظ على الملفات.
- `git push --force` → بيعيد كتابة تاريخ الـ remote ويخفي commits؛ البديل: `git push --force-with-lease` فقط بعد مراجعة `git fetch`.
- `git clean -fd` / `git clean -fdx` → يحذف ملفات ومجلدات غير متتبعة؛ افحص بـ `git clean -nd` أولًا ولا تستخدمه بدون نسخة احتياطية.
</Callout>

## 2. Most Used


| Command | What it does | Quick example |
|---|---|---|
| `git status` | يعرض حالة الـ Working Tree والـ Staging Area | `git status` |

| `git commit -m "msg"` | يسجل Snapshot جديدة برسالة | `git commit -m "fix: handle empty input"` |

| `git switch -c feature/x` | ينشئ Branch جديد وينتقل إليه | `git switch -c feature/login` |
| `git push -u origin feature/x` | يرفع الفرع ويضبط التتبع | `git push -u origin feature/login` |
| `git pull --ff-only` | يجلب ويحدث باستخدام Fast-forward فقط | `git pull --ff-only` |

## 9. Undoing Changes
<a href="/docs/version-control/git-and-github/undoing-changes" class="inline-flex items-center gap-2 rounded-full border border-border bg-surface px-3 py-2 sm:px-4 sm:py-2 text-xs sm:text-sm font-medium shadow-sm hover:border-accent/50 transition-colors">Full explanation Undoing Changes <span aria-hidden="true" style="font-size:1.4rem;">→</span></a>


| Command | What it does | Quick example |
|---|---|---|
| `git restore <file>` | يلغي تعديلات غير معمولة لها commit في الملف | `git restore src/app.js` |
| `git restore --staged <file>` | يزيل الملف من الـ Staging مع الاحتفاظ بتعديلاته | `git restore --staged src/app.js` |
| `git reset --soft HEAD~1` | يحرك الـ branch ويحتفظ بالتغييرات staged | `git reset --soft HEAD~1` |
| `git reset --mixed HEAD~1` | يحرك الـ branch ويعيد التغييرات إلى unstaged (افتراضي) | `git reset --mixed HEAD~1` |
| `git reset --hard HEAD~1` | يحرك الـ branch ويعيد ضبط Index وWorking Tree (خطير) | `git reset --hard HEAD~1` |
| `git revert <commit>` | ينشئ commit جديد يعكس تغييرًا سابقًا بأمان | `git revert a1b2c3d` |
| `git reflog` | يعرض سجل تحركات HEAD لاستعادة commits | `git reflog -10` |
| `git commit --amend` | يستبدل آخر commit برسالة أو ملفات جديدة | `git commit --amend -m "docs: clarify recovery"` |

| Command | What it does | Quick example |
